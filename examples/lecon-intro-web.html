Leçon 1 : Fondamentaux de la Sécurité Web

Lors du développement d'une application web moderne, la validation des entrées et le contrôle d'accès côté serveur sont indispensables. Le client (navigateur) ne doit jamais être considéré comme fiable.

1. Authentification par JWT

Un JSON Web Token (JWT) permet d'authentifier les requêtes API sans session serveur. Il doit toujours être signé avec un secret robuste stocké dans les variables d'environnement (.env).

Bon réflexe : Toujours vérifier le rôle et l'appartenance aux ressources (éviter les failles IDOR) dans chaque contrôleur backend.

2. Protection contre les failles XSS

Le HTML externe ou saisi par un utilisateur ne doit jamais être injecté tel quel dans le DOM principal. L'utilisation d'une <iframe sandbox=""> ou d'un assainisseur strict permet d'isoler le contenu.
